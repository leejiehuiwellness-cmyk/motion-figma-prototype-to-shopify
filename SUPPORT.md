# Support

For support after the GitHub repository is pushed, use GitHub Issues:

https://github.com/leejiehuiwellness-cmyk/motion-figma-prototype-to-shopify/issues

When reporting an issue, include:

- The selected Figma node type.
- The generated `motion-figma-prototype-to-shopify-report.json`.
- A short description of the expected Shopify output.
- Any Shopify Liquid or browser console error.
