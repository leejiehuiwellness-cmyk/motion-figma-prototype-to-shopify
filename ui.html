Prototype motion

This v1 reads Figma prototype triggers, actions, destinations, transitions, easing, duration, overlays, and Smart Animate-like matching layer diffs. Drag, variables, conditionals, video runtime actions, and scroll-linked behavior are reported as warnings.

Onboarding guide

  1. In Figma, open a finished Shopify page, section, component, or component variant design.
  2. Select one frame, component, component set, instance, group, or any layer inside a component/instance. If you select a child layer, Motion exports the nearest supported ancestor as the Shopify section boundary.
  3. For Shopify dynamic content, rename layers with data names such as product.title, product.price, product.image, collection.grid, menu.main, and cart.count.
  4. Add prototype interactions in Figma Prototype mode. Supported v1 interactions include click, hover, press, mouse enter/leave, mouse down/up, after delay, navigate, swap, change-to, open overlay, back, close, and URL.
  5. Run this plugin, review warnings, then click Generate export.
  6. Use Copy Liquid to paste the one-file section into Shopify, or download the ZIP and copy files into a Shopify theme project.
  7. In Shopify Admin, go to Online Store > Themes > Edit code > Sections, add a new section with the generated file name, paste the Liquid, save, then add the section in the theme editor.
  8. If the section references assets, upload the generated files from the ZIP's assets folder into the Shopify theme assets folder.
