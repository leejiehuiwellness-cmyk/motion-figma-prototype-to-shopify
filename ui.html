Prototype motion

Motion reads Figma prototype triggers, actions, destinations, transitions, easing, duration, overlays, prototype routes, detected loops, and Smart Animate-like matching layer diffs. The Animation mode setting controls Enter Once, Enter Replay, Infinite Loop, Scroll Scrub, or Pin Sequence behavior in the generated Shopify runtime.

Onboarding guide

  1. In Figma, open a finished Shopify page, section, component, or component variant design.
  2. Select the desktop frame/section and click Set Desktop. Optionally select the mobile frame/section and click Set Mobile. If Desktop is not set, Motion uses the current selection as desktop.
  3. If you select a child layer, Motion exports the nearest supported ancestor as the Shopify section boundary.
  4. For Shopify dynamic content, rename layers with data names such as product.title, product.price, product.image, collection.grid, menu.main, and cart.count.
  5. For SVG asset export, name the layer with a clean SVG filename such as home_solution.svg.
  6. Add prototype interactions in Figma Prototype mode. Supported v1 interactions include click, hover, press, mouse enter/leave, mouse down/up, after delay, navigate, swap, change-to, open overlay, back, close, and URL.
  7. Choose Animation mode: Enter Once, Enter Replay, Infinite Loop, Scroll Scrub, or Pin Sequence.
  8. Run this plugin, review warnings, then click Generate export.
  9. Open Assets to rename generated image/SVG files, then click Save and Run so Copy Code, Copy CSS, Copy JS, ZIP, manifest, and report all use the same filenames.
  10. Use Copy Code for the Shopify section file, or download the ZIP for the Liquid, optional CSS/JavaScript developer copies, manifest, report, and assets.
  11. ZIP/external mode includes shared runtime assets: assets/motion-figma-gsap-runtime.css and assets/motion-figma-gsap-runtime.js. Copy Code mode already includes that code inline.
  12. In Shopify Admin, go to Online Store > Themes > Edit code > Sections, add a new section with the generated file name, paste the Liquid, save, then add the section in the theme editor.
  13. If the section references image or SVG assets, upload those generated files from the ZIP's assets folder into the Shopify theme assets folder. CSS and JavaScript are already included in Copy Code mode.
